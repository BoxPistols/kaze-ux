# Kaze Design System — 設計思想

## 理念

> 整えて、委ねる。

土台を整えるところまでを引き受け、その先はつくる人に委ねる。

## 使命

**つくる人の手に、確かな土台を。**

意匠の正解は持たない。持っているのは、どんな見た目を選んでも
崩れない土台だけ。

完成とは、足し終えた時点ではなく、削り終えた時点を指す。

## 価値基準

|          |                                |
| -------- | ------------------------------ |
| **誠実** | 正確。透明。率直。一貫。責任   |
| **抑制** | 簡潔。静けさ。余白。品位。潔さ |
| **開放** | 寛容。平明。共有。越境。継承   |

作り手の規律は、そのまま成果物に現れる。

## 原則

### 1. 守るべき一線

譲れないものを、先に決めておく。決めていないものは、いつのまにか失われる。

### 2. ひとつの拠り所

立ち返る場所を、ひとつに。拠り所がふたつあれば、どちらも信じられなくなる。

### 3. 表現は託す

選ぶ楽しみを、つくる人に残す。整えるのは土台まで。その先には口を出さない。

---

## 下限の定義（原則 3 の具体）

| 要件                                   | 検証方法                                 |
| -------------------------------------- | ---------------------------------------- |
| 本文コントラスト 4.5:1                 | 実際に敷かれる面で測定（半透明は合成後） |
| 操作対象 24×24 以上                    | 描画寸法を測定（WCAG 2.2 SC 2.5.8）      |
| フォント 12px 以上 / ウェイト 400・700 | 実ビルドを描画して測定                   |
| 色はトークン参照                       | ハードコード値を検出                     |

色・書体・余白の**選択**は規定しない。

## 色の構造

塗り面と前景で別のトークンを持つ。面が異なれば必要な前景色も異なるため。

| スロット       | 用途                                          |
| -------------- | --------------------------------------------- |
| `main`         | 塗り面                                        |
| `contrastText` | `main` の面に乗る文字（実測で決定）           |
| `onLight`      | `light` の面に乗る文字                        |
| `textContrast` | 素の背景と `lighter` の面に乗る文字・アイコン |

`primary.main` をそのまま文字色に用いると、明るいセマンティック色は白地で
2.6:1 程度にとどまる。
