# Kaze Design System — 設計思想

## 理念

> デザインを、構造で支える。

共通の構造から、異なる表現が生まれる。

## 使命

**一貫した構造の上に、複数のプロダクトを置く。**

意匠の正解は持たない。同じものが同じ形で現れることだけを保つ。

## 価値基準

|          |                                    |
| -------- | ---------------------------------- |
| **精度** | 正確。均質。厳密。再現。一貫       |
| **簡潔** | 簡素。余白。抑制。静穏。無駄がない |
| **中立** | 非依存。汎用。可搬。開放。継承     |

見えないところに、精度がある。

## 原則

### 1. 拡張に耐える構造

用途が変わっても、壊れない。変化は前提であり、例外ではない。

### 2. 最小の情報量

見えるものが少ないほど、迷いは少ない。足すより、削るほうが難しい。

### 3. 統一された秩序

同じものは、同じ形で現れる。例外は、秩序を薄める。

---

## 下限の定義（原則 3 の具体）

| 要件                                   | 検証方法                                 |
| -------------------------------------- | ---------------------------------------- |
| 本文コントラスト 4.5:1                 | 実際に敷かれる面で測定（半透明は合成後） |
| 操作対象 24×24 以上                    | 描画寸法を測定（WCAG 2.2 SC 2.5.8）      |
| フォント 12px 以上 / ウェイト 400・700 | 実ビルドを描画して測定                   |
| 色はトークン参照                       | ハードコード値を検出                     |

色・書体・余白の**選択**は規定しない。

## 色の構造

塗り面と前景で別のトークンを持つ。面が異なれば必要な前景色も異なるため。

| スロット       | 用途                                          |
| -------------- | --------------------------------------------- |
| `main`         | 塗り面                                        |
| `contrastText` | `main` の面に乗る文字（実測で決定）           |
| `onLight`      | `light` の面に乗る文字                        |
| `textContrast` | 素の背景と `lighter` の面に乗る文字・アイコン |

`primary.main` をそのまま文字色に用いると、明るいセマンティック色は白地で
2.6:1 程度にとどまる。
