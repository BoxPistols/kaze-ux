# Kaze Design System — 設計思想

## Core Belief

> 正直であることが、いちばん外側の品質。

できていないことを、できていないと言えること。**それを言えるものだけが、
できていることを信じてもらえる。** 仕様の正しさより先に、仕様と実物が
一致しているかどうかが信頼を決める。

Kaze は「風」。基盤は主張しない。作るものの背後に回る。

## 何者であるか

**作り手の表現を縛らずに、誰にとっても読めて触れる土台を差し出しつづけるもの。**

意匠を配る仕組みではない。色や形の正解を持っているわけでもない。
持っているのは、**どんな見た目を選んでも壊れない下限**だけ。

一貫性とは、揃えることではない。**迷わせないこと**。

## 3 つの心構え

### 正直

誇張しない。弱点を先に出す。数字を飾らない。分からないときは分からないと言う。
直す前に、まず認める。

### 謙虚

自分の目を疑う。好みで決めない。確かめてから言う。例外を切り捨てない。
**前提から間違えている可能性を、いつも残しておく。**

### 敬意

読む人を迷わせない。選び方を押し付けない。誰にでも届く形にする。
後から来る人に残す。**人にも AI にも同じ顔を向ける。**

## 3 つの原則

### 1. 正直さは、機能である

言っていることと、出来ているものを、一致させつづける。

仕様と実物がずれていても、たいてい何も起こらない。エラーも警告も出ない。
だからこそ、ずれを見つけたときは記述を書き換えるのではなく、
**ずれない形に作り替える**。

### 2. 自由は、土台の上に立つ

表現を縛らないために、譲れない下限だけを決める。

色も書体も余白も、選ぶのは作り手。読めること、触れられること、意味が伝わること。
**ここだけは誰の好みにも譲らない。**

### 3. 風のように、邪魔をしない

基盤は前に出ない。良い土台は、使っているあいだ意識されない。
覚えることを増やさず、選択肢を狭めず、必要なときにだけ姿を見せる。

---

## この信念が、実装ではどう現れているか

心構えは、守り方を持たなければただの標語になる。以下は上の 3 原則が
コードと運用に落ちた形。

### 正直さ → 主張は測ってから書く

- 禁止パターンには**何が違反を止めるのか**を必ず添える。止める仕組みが無い
  ものは「なし」と表に出す
- 検査の対象外にしたものは、理由と件数を必ず出力する
- 検査は導入時に一度壊して赤くなることを確認してから信用する

### 自由 → 縛るのは下限だけ

| 保証する下限                           | 測り方                                         |
| -------------------------------------- | ---------------------------------------------- |
| 本文コントラスト 4.5:1                 | 実際に敷かれる面で測る（半透明は合成してから） |
| 操作対象 24×24 以上                    | 描画した寸法を測る（WCAG 2.2 SC 2.5.8）        |
| フォント 12px 以上 / ウェイト 400・700 | 実ビルドを描画して測る                         |
| 色はトークン参照                       | ハードコードしない                             |

色・書体・余白の**選び方**は縛らない。

### 邪魔をしない → 覚えることを増やさない

- トークン・部品仕様・禁止パターンは生成物。手で書き写さない
- UI ライブラリに依存しない層を分け、CI が依存グラフで保証する
- MUI を使わないプロダクトは CSS を 1 枚読むだけで同じ色に乗れる

## 面ごとに前景色を持つ

色の扱いだけは癖がある。**塗り面と前景で別のトークンを持つ。**

| スロット       | どこに使うか                                  |
| -------------- | --------------------------------------------- |
| `main`         | 塗り面                                        |
| `contrastText` | `main` の面に乗る文字（実測で決定）           |
| `onLight`      | `light` の面に乗る文字                        |
| `textContrast` | 素の背景と `lighter` の面に乗る文字・アイコン |

`primary.main` をそのまま文字色にすると、明るいセマンティック色は白地で
2.6:1 程度しか出ない。**面が違えば必要な前景色も違う。**

## ブランド

- **Primary**: `#0057B8` — 白文字が 6.87:1 出る。ロゴとテーマが `BRAND_BLUE` を
  単一ソースとして共有する
- **Font**: Inter + Noto Sans JP。見出しも本文も同じグロテスクで、階層は太さで作る
- **Grid**: 4px 基準
- **Border Radius**: xs(4) / sm(6) / md(8) / lg(10) / xl(12) / 2xl(16)
