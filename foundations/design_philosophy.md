# Kaze Design System — 設計思想

## 理念

> 規律の上に、自由をつくる。

守るべき下限を定め、それが守られていることを検証しつづける。
下限が保証されているからこそ、その上の表現は自由でいられる。

## 使命

**表現の自由と、品質の下限を、同時に成立させる。**

意匠の正解を配る仕組みではない。いかなる見た目を選んでも満たすべき
最低条件のみを規定し、それが満たされていることを継続的に検証する。

**完成とは、足し終えた時点ではなく、削り終えた時点を指す。**

## 価値基準

|            |                                                          |
| ---------- | -------------------------------------------------------- |
| **実証性** | 実測。反証可能。透明。再現性。誠実さ                     |
| **抑制**   | 簡潔。削ぎ落とす。装飾を疑う。借り物を使わない。一点集中 |
| **開放性** | 非依存。可搬性。拡張可能。相互運用。機械可読             |

**作り手の規律は、そのまま成果物に現れる。** 意匠を規定しないことは、
意匠に無関心であることを意味しない。基盤が主張を持たないのは選択であり、
その選択を保つには、足さずに済ませる判断を繰り返す必要がある。

## 原則

### 1. 強制をともなう規範

止める仕組みを持たないものを、規範とは呼ばない。強制の所在を、規約と
同じ場所に記す。無い場合は「なし」と明示する。

### 2. ひとつの定義

人が読む記述は、機械が読む定義から導く。ふたつの記述が併存すれば
必ず乖離する。単一の定義から生成し、その鮮度を絶やさない。

### 3. 下限だけの保証

読めること、触れられること、伝わること。色も書体も余白も、選ぶのは作り手。

---

## 下限の定義（原則 3 の具体）

| 要件                                   | 検証方法                                 |
| -------------------------------------- | ---------------------------------------- |
| 本文コントラスト 4.5:1                 | 実際に敷かれる面で測定（半透明は合成後） |
| 操作対象 24×24 以上                    | 描画寸法を測定（WCAG 2.2 SC 2.5.8）      |
| フォント 12px 以上 / ウェイト 400・700 | 実ビルドを描画して測定                   |
| 色はトークン参照                       | ハードコード値を検出                     |

色・書体・余白の**選択**は規定しない。

## 色の構造

塗り面と前景で別のトークンを持つ。面が異なれば必要な前景色も異なるため。

| スロット       | 用途                                          |
| -------------- | --------------------------------------------- |
| `main`         | 塗り面                                        |
| `contrastText` | `main` の面に乗る文字（実測で決定）           |
| `onLight`      | `light` の面に乗る文字                        |
| `textContrast` | 素の背景と `lighter` の面に乗る文字・アイコン |

`primary.main` をそのまま文字色に用いると、明るいセマンティック色は白地で
2.6:1 程度にとどまる。
